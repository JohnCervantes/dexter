# Dexter
## https://dexternewblood.com

## what is this project about?
+ A fan-made website for promoting a popular TV show called dexter.

## Technologies used: 

+ back-end - Next.js, React, Apollo client 3, Tailwind CSS, AWS S3
+ API - GraphQL, Mongoose, next API routes
+ Database - MongoDB 
+ CI/CD - Vercel, GitHub Actions

*Latest versions of these node packages are used in this project*
