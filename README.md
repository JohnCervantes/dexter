# Dexter

[Live Site](https://dexter-new-johncervantesprotonmailcs-projects.vercel.app/)

## Overview

Dexter is a fan-made website dedicated to promoting **Dexter: New Blood** and the original **Dexter** TV series. The site features information, media, and interactive content for fans of the franchise.

---

## Features

- Show information, cast, and episode guides
- Media gallery and fan content
- Responsive design for all devices
- Fast and secure with modern web technologies

---

## Technologies Used

- **Front-end:** Next.js, React, Tailwind CSS, Apollo Client 3
- **Back-end/API:** Next.js API routes, GraphQL, Mongoose
- **Database:** MongoDB
- **Cloud/Storage:** AWS S3
- **CI/CD:** Vercel, GitHub Actions

---

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/yourusername/dexter.git
   cd dexter
   ```

2. **Install dependencies:**
   ```sh
   npm install
   ```

3. **Set up environment variables:**
   - Create a `.env.local` file based on `.env.example`
   - Add your MongoDB URI, AWS credentials, etc.

4. **Run the development server:**
   ```sh
   npm run dev
   ```

5. **Open [http://localhost:3000](http://localhost:3000) to view it in your browser.**
